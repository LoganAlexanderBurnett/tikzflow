# TikZFlow help

TikZFlow is a visual editor for TikZ flowcharts. The code and the canvas are side by side and follow each other: drag a node and one line of code changes; edit the code and the picture redraws. It runs entirely in your browser. Nothing you draw is uploaded.

> **Your work is kept in this browser only.** It isn't stored on any server, so clearing this site's data, or opening TikZFlow in another browser or on another computer, won't show it. Save important diagrams as files. [Saving, tabs and your work](saving.md) explains how.

## Quick tips

- Press <kbd>?</kbd> in the editor for the list of shortcuts.
- Bookmark [tikzflow.pages.dev/editor/](/editor/) to go straight to the editor.
- Use the search box on the left, or press <kbd>/</kbd>, to find a topic.
