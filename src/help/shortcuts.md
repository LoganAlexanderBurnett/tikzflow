# Keyboard shortcuts

Press <kbd>?</kbd> in the editor (outside the code pane) to see this list there. On a Mac, use <kbd>⌘</kbd> where it says <kbd>Ctrl</kbd>, and <kbd>Option</kbd> for <kbd>Alt</kbd>.
