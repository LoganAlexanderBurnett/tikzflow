    Keyboard shortcuts

    Press ? in the editor (outside the code pane) to see this list there. On a Mac, use ⌘ where it says Ctrl, and Option for Alt.

    Anywhere

    ?Show or hide the shortcut list
    Ctrl + SSave (to the file, else a download)
    Ctrl + ZUndo, in the code and on the canvas
    Ctrl + Y or Ctrl + Shift + ZRedo
    EscClose a menu, panel or the shortcut list

    Canvas

    Click the canvas first.

    TabAdd a node connected after the selected one (in an empty picture, the first node)
    EnterAdd a node beside the selected one
    F2Edit the selected node's label (or double-click it)
    Delete or BackspaceDelete the selection; what depended on it is re-attached or pinned
    Menu or Shift + F10Open the selected edge's menu
    Space + dragPan

    Mouse

    Shift + clickAdd to the selection, or take out of it
    Alt + dragMove or resize without snapping
    Ctrl + dragOn a node or a resize handle: move the nodes placed against it too (or only it and its labels, with Move followers too on)
    Shift + dragOn a resize handle: resize from the center
    Right-drag or Middle-dragPan (dragging the background does too)
    WheelZoom, about the pointer
    Right-clickAn edge's menu
    Double-clickEdit a label; on an edge's corner, remove it
    Middle-clickOn a tab, close it

    Tabs

    With a tab focused.

    ← or →Show the tab before or after

    Editing a label

    EnterApply
    Shift + EnterNew line
    TabApply and add the next connected node
    EscCancel

    Edge menu

    ↑ or ↓Move between items
    Enter or SpaceChoose
    → or ←Open or leave a submenu (the anchors)

    Code

    Ctrl + FFind and replace
    Tab or Shift + TabIndent, outdent
    EscThen Tab: leave the code pane by keyboard (Tab alone indents)
