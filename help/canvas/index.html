    Editing on the canvas

    Every change you make on the canvas becomes a small change to the code, and only to the lines it is about. Everything else, your comments and spacing included, stays exactly as you wrote it. Ctrl+Z undoes it, whether you made it on the canvas or in the code.

    #Selecting

    • Click a node to select it. Its code is highlighted in the code pane, and the properties panel shows it.
    • Shift-click adds a node to the selection, or takes it out.
    • Putting the cursor in a node's code selects that node on the canvas.

    #Moving nodes

    Drag a node. While you drag, guides show when it lines up with another node, and it snaps to the distances your picture already uses. When you let go, the code says where it is in the way a person would write it, in this order of preference:

    1. a relation to a nearby node: below=of start, right=1cm of check, below right=7mm and 1.8cm of read;
    2. a line-up with two nodes: at (a |- b);
    3. plain coordinates, only when nothing else fits.

    Hold Alt while dragging to move freely, without snapping.

    #Only the node you drag moves

    In TikZ, a node placed relative to another (below=of read) follows it: move read and everything placed against it goes along. TikZFlow moves only the node you drag. The nodes that were placed against it stay where they are: each is rewritten in the same step, against what the dragged node was placed against when that works (below=2.53cm of start), against another node otherwise, and with coordinates only as a last resort. The status bar names every node it rewrote ("Kept in place: small (below=2.53cm of start)"), and Ctrl+Z undoes it all at once.

    Labels move with their node. A node placed against the one you drag that only labels it moves along: it draws only its text (no border or fill), hangs off that node alone, has no edge to it, nothing else is placed against it, it isn't a group's title, and it doesn't sit inside another shape. In the Venn diagram template, a set's name and its own count go with the circle; the counts in the overlaps stay, since they belong to two sets.

    While you drag, the nodes that follow the one you hold have a faint outline: dashed when they stay where they are, solid when they move along.

    To move a node together with its followers, as TeX would, hold Ctrl (⌘ on a Mac) while you drag. You can press or let go of it during the drag. Move followers too in the toolbar makes that the default (this browser remembers it); Ctrl then moves only the node.

    If a node that would move along can't be rewritten (it is in a block kept as it is, say), the drag is refused and the status bar says why. Hold Ctrl to move it along instead.

    #What a node follows

    Select a node, and Placement in the properties panel lists what it is placed against ("Follows read: below=of read") and the nodes placed against it. Nothing moves when you change these:

    • Unlink next to an entry cuts that one link: the node is placed against something else where it stands, or pinned with coordinates.
    • Detach cuts all of them: the node gets its current position as coordinates, and the nodes placed against it are re-attached to something else (or pinned). With several nodes selected, it detaches each of them.

    A group's or a lane's box always follows its members, and a label on an edge follows the edge: those aren't placement links.

    #Moving several nodes

    Select several nodes with Shift-click and drag one of them: they move together, and each is written relative to what it was placed against. Nodes outside the selection that were placed against it stay where they are, as for one node (hold Ctrl to move them along). Dragging a group's or a lane's box moves everything in it.

    #Chains

    Nodes placed with the chains library (on chain) can be dragged too. The first time you drag one, the editor writes the chain out as ordinary positions so the node can move, and says so in the status bar.

    #Adding nodes

    • The palette along the top of the canvas has Process, Decision, Terminal, I/O, Connector and Document, then your picture's own node styles under "This figure". Click one to add it after the selected node, connected to it (or in the middle of the view when nothing is selected), or drag it onto the canvas. A shape's style is added to your \tikzset the first time you use it.
    • Tab adds a node connected after the selected one. In an empty picture it adds the first node.
    • Enter adds a node beside the selected one.

    New nodes get names made from their labels, such as (check), and never clash with names already in the picture.

    #Editing labels

    Double-click a node, or select it and press F2, to edit its label in place. Enter applies, Shift+Enter starts a new line, Tab applies and adds the next connected node, and Esc cancels. Labels can hold math ($n \le 1$); the canvas draws it with KaTeX until TeX's own picture is ready.

    #Resizing

    Select one node and drag a handle on its corners or sides. The edge or corner opposite the handle stays put. Hold Shift to resize from the center, or Alt to turn off snapping. As in dragging, the nodes placed against the one you resize stay where they are (its labels move with it), unless you hold Ctrl (⌘ on a Mac) or Move followers too is on. Resizing a style ("All process nodes") changes every node that uses it, as an edit in the properties panel does. Sizes snap to whole millimeters and to the sizes of other nodes, and are written as minimum width and minimum height (or text width when the text should wrap).

    To give several nodes the same size, select them (the first one you click sets the size) and use Match width or Match height in the properties panel.

    #Deleting

    Press Delete (or Backspace), or use Delete node in the properties panel. The edges to and from the node go too. Nodes that were placed relative to it are attached to what it was placed against, or kept where they are, so the code never refers to a node that is gone. A node in a group's box is taken out of the box.

    #Panning and zooming

    • Scroll to zoom, about the pointer.
    • Drag the background, or drag with the right or middle mouse button, or hold Space and drag, to pan.
    • Fit in the toolbar fits the picture to the canvas.

    #Accessibility views

    View in the toolbar shows the picture in grayscale, or as someone with red, green or blue color blindness would see it. Only the preview changes: your code and your exports keep their colors. Text that is hard to read against its fill gets a marker, and the summary counts it ("1 low contrast"); select the node and the properties panel offers black or white text that reads well.
